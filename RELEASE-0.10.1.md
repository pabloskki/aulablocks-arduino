# AulaBlocks Arduino 0.10.1

Ayudas para niños al dejar el mouse sobre los bloques, sin hacer clic. Explican qué hace cada bloque, qué dato entrega, unidades y ejemplos. Incluye ayudas para los bloques principales y los 29 bloques de los 11 paquetes de sensores.

- Windows x64: instalador y metadatos para actualizar desde el programa.
- Linux Mint Intel/AMD 64 bits: instalador .deb y alternativa .tar.gz. Instala el .deb sobre la versión anterior; Linux no dispone de instalación automática.
- Sensores: descomprime Sensores-AulaBlocks-0.10.1.zip e instala los .aulasensor mediante «Añadir sensor», o utiliza la actualización de biblioteca. El mismo ZIP sirve para Windows y Linux. Actualiza también los sensores que conserve cada proyecto para ver las ayudas nuevas.
- Se mantienen código Arduino, bibliotecas, imágenes, pines e identificadores. El programa no añade sensores al proyecto automáticamente.

Pruebas locales: 63 pruebas automatizadas, 22 compilaciones de sensores para Uno y Nano ATmega328PB y comprobación visual de ayuda con eventos de mouse simulados, sin clic ni selección. La construcción de esta entrega vuelve a ejecutar las pruebas en Windows y Linux; Linux verifica también las herramientas extraídas del .deb.

Pendiente: prueba física de esta entrega con placas y sensores, y validación en un equipo Linux Mint real. No confundir compilación correcta con prueba de hardware. Los avisos de dependencias existentes no se han corregido en esta actualización de ayudas; se detallan en AYUDAS-0.10.1.md del código fuente.

Se conservan las versiones anteriores en GitHub Releases.

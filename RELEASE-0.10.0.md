# AulaBlocks Arduino 0.10.0

Versión numerada 0.10.0, sin el sufijo beta. Sustituye a 0.10.0-beta.5.
Los instaladores se regeneran con el número interno actualizado; no se renombran
los binarios anteriores. No hay cambios funcionales respecto a beta.5.

- Windows x64: instalador fijo y metadatos de actualización desde el programa.
- Linux Mint Intel/AMD 64 bits: instalador fijo .deb y alternativa .tar.gz.
  Instalar el .deb sobre la versión anterior. No hay instalación automática en Linux.
- Los once sensores y sus bibliotecas conservan sus versiones e identificadores.
  No es necesario reinstalarlos si ya se actualizaron para beta.5.
  El ZIP Sensores-AulaBlocks-0.10.0.zip sirve para ambos sistemas.

La denominación 0.10.0 no amplía la validación física: Windows cuenta con la prueba
básica reportada por el usuario; falta verificar en Linux Mint real la interfaz,
USB, carga a la placa y monitor serial. Las pruebas automatizadas y compilaciones
se ejecutan de nuevo para los instaladores de esta entrega.

Las versiones anteriores se conservan en GitHub Releases.

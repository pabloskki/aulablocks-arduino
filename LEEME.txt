AULABLOCKS ARDUINO 0.10.0-beta.1
================================

AulaBlocks permite programar Arduino con bloques, comprobar el programa,
guardar el archivo .ino, cargarlo directamente y usar un monitor serial.

PLACAS COMPATIBLES
- Arduino Uno con ATmega328P.
- Nano compatible con ATmega328PB mediante MiniCore.

SENSORES
Los sensores no forman parte del programa principal. Se instalan como archivos
.aulasensor desde “Añadir sensor” o desde la Biblioteca en línea. Cada paquete
incluye sus bloques, código, imagen, información de conexiones y, cuando se
necesitan, sus bibliotecas de Arduino.

Al guardar un proyecto se registra la lista y versión de los sensores usados.
Al abrirlo en otro PC, AulaBlocks avisa si falta alguno o si debe actualizarse.

DESARROLLO Y PRUEBAS
- npm ci                 instala exactamente las dependencias aprobadas.
- npm test               ejecuta las pruebas automáticas.
- npm run build          construye la interfaz.
- npm run test:sensors   compila cada sensor para Uno y Nano; requiere runtime.

Los runtimes se reconstruyen con:
- npm run prepare:windows-runtime
- npm run prepare:linux-runtime (después del runtime de Windows)

No se debe publicar una versión hasta completar PRUEBAS-ARDUINO.md.
